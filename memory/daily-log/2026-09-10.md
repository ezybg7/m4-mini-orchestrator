**Finding worth keeping.** basic-memory is a **second producer** on this vault.
It canonicalizes YAML (block sequences, ISO timestamps, wrapped values) and
asynchronously re-prepends its own `permalink` block after an external edit,
leaving two stacked frontmatter blocks. `scripts/okf_fm.py` parses the canonical
form with no dependency. The first attempt at the fix was wrong: merging by
rewriting the whole file converted basic-memory's canonical YAML back to our
flat style, which its watcher read as a change — it re-prepended, we re-merged,
forever. `okf-normalize.py` now **collapses surgically**: it drops the redundant
leading block and leaves the rest byte-for-byte, so there is nothing for the
watcher to react to. `backup.sh` runs converge-and-check before every commit.
The sync is asynchronous, so a check run seconds after a bulk edit can still
see stacked blocks; it settles. This is OKF's
producer/consumer independence working as advertised — and the reason the
frontmatter parser had to be written properly rather than as a flat split.

no integration layer, and there should not be one. Tools cooperate because they
share a directory of markdown files with frontmatter. The contract just has to be
written down, so it now is:
[`references/tool-harmony.md`](../../references/tool-harmony.md) — every tool,

### What broke — six gaps, five fixed

1. **The contract said *how* but not *what*.** `01_rehearse` named the Neon
   entity and the safety rules but not the note listing which migrations are
   outstanding and their assert counts. A cold agent would have known how to
   rehearse and not what. Exactly ICM's warning: a file absent from `## Inputs`
   is a file the agent must guess at. **Fixed** — cost went 2,311 → 4,028 tokens,
   still in range, and now sufficient. Cheap context that is insufficient is
   worse than expensive context.
2. **Six index rows misdirected.** Two titles were filename slugs; the
   monetization note's derived description read *"Review round 1 (2026-09-04
   ~22:20 EDT) — decisions folded into the plan"* — nothing about monetization.
   Clean pattern: derivation is fine for daily-logs (whose description genuinely
   IS a heading list) and useless for substantive notes. **Fixed by hand.**
3. **`findings.md` was the one undated stage output** of seven. A later run could
   read a previous run's evidence and commit against it — the exact failure the
   nightly's honesty rule exists to prevent. **Fixed**; `02_skills` now stops if
   there is no file for today rather than reading an older one.
4. **Index rows rendered YAML quoting** — any description containing `": "` had
   to be quoted in the file, and the quote leaked into the row. **Fixed.**
5. **"Add a pipeline per SPEC §2.2" was not actionable** — §2.2 is a table of
   principles, not a procedure, so the first move would be copy-and-edit, which
   is how conventions drift. ICM ships a workspace-builder for this reason.
   **Fixed**: `scripts/new-pipeline.py` writes conformant contracts *and*
   registers them in the index — my first version didn't, so the pipeline it
   created was born an orphan and failed the checker.
6. **The archive index grows a row per day forever** — 734 tokens for 48 rows
   today, ~5,500 in a year. **Not fixed**; fine now, and grouping by month is the
   obvious answer when it stops being fine.

7. **I reintroduced the very bug I had fixed** — while hand-writing those six
   descriptions I wrote `'…as Hermes's local inference node…'`. Inside single
   quotes an internal apostrophe must be doubled, so the quoting broke,
   basic-memory could not parse the file, and it went back to prepending its own
   block. I had bypassed my own `yaml_scalar()` by editing with a raw
   substitution. **Fixed**, and the checker now validates *broken* quoting, not
   just *missing* quoting — it previously only caught unquoted `": "`. Verified
   by reintroducing the fault and watching it fail.
